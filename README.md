# 그리라인 (GRI LINE)

D5 Render 렌더를 웹툰 선화 PSD로 만드는 윈도우 프로그램입니다 — 외부 · 내부 라인, 재질 분리, 하늘 분리, 업스케일, 폴더 지켜보기까지 한 창에서. — 모모드롭

## 받기

**[최신 설치 파일 받기 →](https://github.com/pak6835-create/griline-releases/releases/latest)**
(`GriLineSetup-버전.exe`를 받아 실행하세요)

- 설치할 때 «Windows의 PC 보호» 창이 뜨면 **추가 정보 → 실행**을 누르세요.
- 모든 기능이 무료입니다. 도움이 됐다면 모모드롭에서 후원해 주세요 — 후원하면 받는 키를 넣으면 프로그램 안 모모드롭 소식이 사라집니다.
- 설치한 그리라인은 새 버전이 나오면 알아서 알려 주고 받습니다.
- D5 Render에서 이미지와 함께 Sky Mask · Material ID 채널을 출력해 두세요(모서리 선까지 쓰려면 AI Normal도).

그리라인은 D5 Render 공식 제품이 아니며 D5 Render와 관계가 없습니다.

## 이 저장소

설치 파일과 자동 업데이트 파일만 올려 두는 곳입니다(프로그램 소스 코드는 없습니다).
업데이트 파일은 모모드롭 서명이 맞아야만 그리라인이 받습니다.
